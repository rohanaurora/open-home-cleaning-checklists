# Contributing

Useful corrections and practical improvements are welcome.

## Good contributions

- Fixing unclear task names or notes
- Improving CSV or JSON consistency
- Adding accessible print formats
- Adding translations with a named reviewer
- Adding validation or documentation examples

## Please avoid

- Unsupported safety, insurance, pricing, or guarantee claims
- Customer, cleaner, or private operational data
- Location-specific facts presented as universal rules
- Promotional keyword stuffing
- Content copied from another company without permission

Open an issue or pull request with a short explanation of the use case and what changed.
